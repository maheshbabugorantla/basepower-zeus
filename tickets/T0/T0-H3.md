# T0-H3 — Download the Travis County parcel file and record its fields

## What to build

The TxGIO parcel MapServer lists `Query` but refuses every query (HTTP 400, capability not supported), so M1-P1 cannot
page parcels over REST. Download the Travis County StratMap parcel file from the TxGIO DataHub in a browser (the page returns
403 to curl), or the TCAD GIS export if DataHub is blocked, into `data/raw/parcels/` (git-ignored). Record the source URL,
retrieval time, file name, and the populated fields. Known layer fields include `prop_id`, `geo_id`, `situs_addr`,
`mail_addr`, `stat_land_use`, `loc_land_use`, `year_built`. Answers open question 1.

## Acceptance criteria

- [ ] File is in `data/raw/parcels/` with its source URL and retrieval time in `checks/T0-H3.md`
- [ ] `checks/T0-H3.md` states whether Travis rows populate land-use and mailing-address fields
- [ ] `checks/T0-H3.md` states which field matches the Austin permits `tcad_id` (10 digits, e.g. `0340060502`); likely `geo_id`
