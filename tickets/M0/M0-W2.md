# M0-W2 — App shell: top bar, navigation, Sources page

## What to build

The product shell every page sits in (DESIGN.md §1 and §5 Navigation). The top bar holds the **Base Power Zeus** wordmark, a county
switcher (Travis only until M3), a freshness summary from `api.source_freshness` that stays quiet unless a source is past its refresh cycle,
and an Export slot (disabled until M5). Navigation shows only routes that exist (Overview, Sources in M0; later milestones add Ranking and
Segments). The **Sources** page lists every `api.sources` row: dataset, URL, retrieval time, SHA-256 (copyable), rows, runner, latest run
status, and a raw-file link. It is the demo's proof that every number is real. Read `DESIGN.md` and `PRODUCT.md` before any UI work; tokens and components come from `web/styles/` and `web/components/ui/` (M0-W0).

## Acceptance criteria

- [x] Sources page renders the real `api.sources` rows (or "not loaded" when empty)
- [x] The freshness summary shows a stale badge only for stale sources
- [x] Keyboard navigation reaches every top-bar control with a visible focus ring
