# M0-P2 — pipelines.check CLI: manifest, rows, provenance, reconcile

## What to build

The command every acceptance block calls. `manifest --source X`: every Storage object has a manifest row and its recomputed
SHA-256 matches (check 1). `rows --table T --min N`. `provenance`: every non-null value in every `api` view has a `source_id`
resolving to a manifest row (check 2). `reconcile --source X`: rows loaded = raw rows − logged filter drops (check 5).
`untouched --except T1,T2`: other tables' row counts unchanged since a snapshot (guards parallel pipeline tickets).
