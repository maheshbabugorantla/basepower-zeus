# M0-D0 — Orchestration harness: CLAUDE.md, agent roster, dag.py, no-mock check

## What to build

Prefactor that everything else runs on. `CLAUDE.md` carries the tracer-bullet prompt and the real-data instruction block.
`.claude/agents/` holds schema-dev, pipeline-dev, web-dev, platform-dev, verifier (all `model: claude-sonnet-5`) and the
orchestrator. `.claude/settings.json` sets `CLAUDE_CODE_SUBAGENT_MODEL=claude-sonnet-5` and `CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1`.
`scripts/dag.py tickets/<Mn>/` prints waves from `depends_on` (cross-milestone deps count as satisfied when merged) and fails on
a cycle or on two same-wave tickets with overlapping `owns`. `scripts/no_mock_check.py` implements automated checks 3, 4 and 6:
fake-data libraries, `random`/`np.random` in pipeline code, literal record arrays > 5 rows, mock/fake/dummy/sample file names,
fixtures without a recorded source object and byte range, and `COALESCE(x, 0)` / `fillna(0)` on signal columns.
`CLAUDE.md` and `.claude/agents/web-dev.md` tell every agent to read `DESIGN.md` and `PRODUCT.md` before any UI work.

## Acceptance criteria

- [ ] `python scripts/dag.py tickets/M0/` prints waves D0 → D1,S1 → P1,P2,W1 → V1
- [ ] dag.py tests cover a cycle and an owns overlap, using the real ticket files copied and edited in a temp dir

- [ ] `claude --agent orchestrator` loads and lists the roster
- [ ] `CLAUDE.md` and `.claude/agents/web-dev.md` both require reading `DESIGN.md` and `PRODUCT.md` before UI work

Real-data rule applies: no synthetic, sample, mock, or placeholder data, including in tests. Every loaded row traces to a raw file with an `ops.source_manifest` row. Missing stays null with a reason. Edit only the `owns` paths.
