# M0-W0 — Base Power Zeus design system: tokens, type, base components

## What to build

Implement the repo-root `DESIGN.md` (Base Power Zeus theme, derived from Base Power's own design language): color tokens
for light and dark, type scale, spacing, and the base components every page reuses (card, stat, badge, table, drawer,
"not loaded" and "not available" states, provenance link). Map and chart palettes come from the same tokens. No page work here.

The signature component is the **provenance popover** (DESIGN.md §5): every sourced number is a text-styled button with a
dotted underline that opens a native-popover-API popover with dataset, URL, retrieval time, truncated SHA-256 (copy for full),
pipeline run ID, runner, rows in/loaded, and a raw-file link. "Not loaded" (pipeline has not run) and "not available" (no public
source) are two visibly different states, each with its reason written out and a hatch pattern for maps.

## Acceptance criteria

- [x] Tokens in `web/styles/` match `DESIGN.md` one to one
- [x] Base components render in light and dark
- [x] Text and data colors meet WCAG AA contrast
- [x] Provenance popover is keyboard-operable and is not clipped inside scroll containers
- [x] "Not loaded" and "not available" render differently and both show a reason
