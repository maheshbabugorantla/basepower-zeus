# M0-S1 — Migration 0001: ops/core/api schemas, manifest, outage-by-county contract

## What to build

`create extension if not exists postgis with schema extensions;` schemas `ops`, `core`, `api`; `ops.source_manifest`
(source, url, retrieved_at, sha256, bytes, rows, runner, storage_key); `ops.pipeline_runs` (run id, source, status, cursor,
rows_in, rows_loaded, filter drop counts, started/finished); `core.outage_county_year`; `api.county_outage` (every row carries
its `source_id`s); `api.source_freshness` (last successful run per source + refresh cycle: permits 7 d, ERCOT 1 d, others per
publisher); RLS on every table with no anon policies; private Storage bucket `raw`.

- [ ] `supabase db push` (or psql on POSTGRES_URL_NON_POOLING) applies cleanly to the live project
- [ ] Every table has RLS enabled and no anon policy (query `pg_policies`)
- [ ] Bucket `raw` exists and is private
