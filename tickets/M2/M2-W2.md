# M2-W2 — On-demand Google Solar panel on the home page

## What to build

Route handler `/api/solar/[prop_id]` calls the Solar API for the one home being viewed and returns it live. Never stored or cached (Google terms).

## Acceptance criteria

- [ ] `/home/[prop_id]` shows roof/solar facts for a real Travis home
- [ ] No Solar response is written to the DB or a cache
