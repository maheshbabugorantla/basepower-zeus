# M2-W4 — Show regulated vs deregulated (retail choice) market per home

## What to build

User request: show whether a home is in a deregulated (retail choice / Power to Choose) or a not-deregulated market. Source: the cited manual
file data/manual/retail_market.csv (per EIA utility number: retail_market, plain-language line, source_url, verbatim quote, retrieved_at — all
from Base's own pages). Load it like the utility crosswalk (raw file unchanged to Storage + manifest; core.retail_market keyed by EIA number;
api view). Show it on the home page next to the distributor ("Austin Energy — municipal utility, no retail choice" / "Oncor — deregulated:
retail choice") with the quote in the provenance popover, and split the "Can Base serve this home?" counts by market. Request-time reads are
primary-key lookups by the home's territory_eia_id (no scans). Unknown distributors show not-available with a reason.

## Acceptance criteria

- [ ] Home page shows the market line with provenance for Austin Energy and Oncor homes
- [ ] Serve panel shows counts by market
- [ ] Every query < 50 ms
