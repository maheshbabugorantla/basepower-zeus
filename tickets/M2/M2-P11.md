# M2-P11 — Coverage gaps: where Base is not yet, but backup demand is proven

## What to build

User request: find Base Power coverage gaps — areas where homes are very likely to buy backup power but are not Base customers —
using TCAD-parcel-level permit data, and bucket each zone as already covered vs potential, ranked by our proxy signals.
Orchestrator's real-data preview (Austin permit raw file; Base = contractor_company_name exactly 'Base Power'; permits join parcels by
permits.tcad_id = parcels.geo_id): 327 Base permits -> 283 Base-servable Travis homes; 1,703 homes with battery/generator by other
installers; 134,347 prospects with permit coverage; 19,393 prospects outside the City of Austin permit area (coverage NOT observable —
never shown as 'no Base customers'); Base = 14.2% of backup installs in covered block groups; 211 of 516 covered block groups have
backup demand but zero Base customers.
Build: per home bucket in a precomputed table (base_customer | other_backup | prospect | not_observable) from core.permit_timelines
(M2-P9a: is_base_power, label, tcad_id) — history to date; per block group: homes, base_customers, other_backup, prospects,
base_share_of_backup, backup_penetration, mean prospect score at default weights, and gap_score = expected prospect demand
(sum of prospect scores) x (1 - Base share of existing backup), anchored 0-1. Web: a /ranking/coverage view (map colored by gap
score with a legend; zones bucketed 'Covered by Base' / 'Demand proven, Base absent' / 'Untapped' / 'Not observable (no city permit
data)'), and the county ranking excludes homes that already have backup by default (toggle to include). Privacy: never label an
individual address as a Base customer or show another installer's name per home — per-home buckets only drive exclusion; zone
views show counts. All counts traceable to the permit file + parcel roll.

## Acceptance criteria

- [ ] Bucket counts match a direct recount of the raw permit file joined to parcels
- [ ] Coverage view shows the four zone buckets with counts and a legend; not-observable zones are never shown as gaps
- [ ] Default ranking excludes homes with existing backup; toggle restores them
- [ ] No page shows an individual address tagged as a Base customer; every request-time query < 1 s
