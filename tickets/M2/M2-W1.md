# M2-W1 — Gate reason counts and live weight sliders

## What to build

Show `api.gate_counts` as one horizontal funnel with counts per exclusion reason (not a grid of cards). Sliders call `api.top_homes(weights)` and re-rank without a pipeline run. Each slider shows its weight as a % of the total; one action resets to equal weights. After a re-rank, rows that moved show their change (↑3 / ↓2) for 2 s, with an instant fallback under `prefers-reduced-motion`. Weights are labeled as team choices. Read `DESIGN.md` and `PRODUCT.md` before any UI work; tokens and components come from `web/styles/` and `web/components/ui/` (M0-W0).

## Acceptance criteria

- [ ] Moving a slider re-ranks the list
- [ ] Gate counts render the "not loaded" state before the gate pipeline runs
- [ ] Rank changes are shown after a re-rank
- [ ] Reset returns every weight to equal
