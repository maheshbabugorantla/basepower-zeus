# M4-P4 — Predictive headline score: likelihood of adding backup in the next 12 months

## What to build

Base Power engineers prefer predictive over descriptive signals, so the headline score becomes a calibrated prediction.
Outcome: a gated home receives a battery or generator permit (core.permit_timelines, joined by tcad_id = parcels.geo_id).
Out-of-time design on the permits we have (2023-09 .. 2026-09): TRAIN with features as of 2024-07-01 (only data known before it:
the home's own prior solar/EV/panel/battery/generator permits, parcel facts incl. market value and year built, block-group ACS
incl. income/age, emPOWER, flood, outage term, neighbour adoption rate excluding the home) and label = install in 2024-07-01..
2025-06-30; TEST on features as of 2025-07-01 and label = install after it. Grouped spatial cross-validation by block group inside
training. Logistic regression baseline + gradient boosting (XGBoost or sklearn HistGradientBoosting); keep the one with better
out-of-time AUC; isotonic/Platt calibration. Report out-of-time AUC, PR-AUC, top-decile lift and a calibration table in
checks/M4-P4.md. Final fit uses features as of today to predict the next 12 months. Write core.home_propensity (prop_id pk,
p_install_12m, relative_to_county (p / county base rate), decile, top-3 SHAP reasons as (feature, direction, value), model_version,
trained_through, source_ids) + api.home_propensity + core.model_card (metrics) + api views; zeus_web_ro grants/RLS.
Homes outside the Austin permit area and Harris/Williamson homes get predictions from the same model with permit features null
(model must handle missing natively), flagged `extrapolated_from='austin_installs'`. Never a percentile; never invented values.

## Acceptance criteria

- [ ] Out-of-time AUC and top-decile lift reported in checks/M4-P4.md from a held-out later period
- [ ] core.home_propensity has a row per gated Travis home with calibrated p and top-3 reasons
- [ ] Calibration: predicted vs observed install rate per decile on the test period within ±50% relative
