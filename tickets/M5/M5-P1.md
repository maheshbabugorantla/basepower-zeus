# M5-P1 — K-Means segments of block groups

## What to build

Unsupervised segmentation of gated Travis and Harris block groups on standardized real features (distributor SAIDI, grid
value, backup intent, share 65+, electric heating, medical need, flood share, gated-home count). Choose k from 3–8 by silhouette
score and report the curve; fixed seed (seeded-model marker from M4-P4). Name each segment from its centroid profile (e.g.
"high outage, older households") and store the naming rule, not hand-picked labels. Assignments to `core.bg_segments`, run
metadata to `core.segment_runs`. M5-H1 then writes one channel recommendation per segment.

- [ ] pytest pipelines/tests/test_segments.py (same seed reproduces identical assignments)
- [ ] checks/M5-P1.md records k, the silhouette curve, centroid profiles and segment names
