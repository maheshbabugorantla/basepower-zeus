# M1-P4 — Travis parcel geometry from the TCAD_public layer

## What to build

Page the Travis County `TCAD_public` layer (`https://gis.traviscountytx.gov/server1/rest/services/Boundaries_and_Jurisdictions/TCAD_public/MapServer/0`; 386,682 parcels,
maxRecordCount 2000) ordered by OBJECTID with a resumable cursor in `ops.pipeline_runs`. Write the page responses unchanged, in
order, as one raw GeoJSON-sequence object in Storage (one manifest row with its SHA-256, the query URL, and the retrieval time).
Load polygons and centroids (EPSG:4326) into `core.parcel_geoms` keyed on `PROP_ID`, with `geo_id`. Chunk so each Vercel call
finishes well under 300 s; the CLI entrypoint may run the whole backfill.
