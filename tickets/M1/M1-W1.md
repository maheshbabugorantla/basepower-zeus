# M1-W1 — Choropleth, top-50 table, home detail, join rate and precision

## What to build

MapLibre choropleth of Travis block groups from `api.blockgroup_scores`; top-50 table from `api.top_homes`; `/home/[prop_id]`
shows the parcel and its permit rows with provenance. A quality panel shows the join rate and classifier precision, which read
"not loaded" until pipelines and M1-H1 land. Basemap: OpenFreeMap Positron (`https://tiles.openfreemap.org/styles/positron`,
no API key), kept muted so the green score ramp carries the color. Block groups with no score use the hatched "not loaded"
fill, never the lowest ramp step. Map and table are linked: hovering a row highlights its block group. Every sourced value uses
the provenance popover; the detail drawer is only for a home's full record. Read `DESIGN.md` and `PRODUCT.md` before any UI work; tokens and components come from `web/styles/` and `web/components/ui/` (M0-W0).

## Acceptance criteria

- [ ] Pages render the honest empty state against the real views
- [ ] Every top-50 row links to `/home/[prop_id]`
- [ ] The map loads with no API key
- [ ] Unscored block groups are hatched, not colored as low scores
